# Hassan Sajjad —  Portfolio

A static portfolio built with plain HTML, CSS and lightweight JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive futuristic visual system
- `script.js` — reveal animation, nav state, cursor glow and architecture sequencing

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
